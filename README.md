# Minimalist iOS Siri Remote for WebScrcpy

Modeled directly after the Apple TV Siri Remote (2nd/3rd Gen aluminum unibody):
- Precision brushed aluminum gradient styling.
- Signature circular clickpad with outer directional clicks + center smooth touch surface for real mouse coordinates.
- Back (`<`), TV/Home (`[ ]`), Play/Pause (`▷II`), Mute, and vertical pill Volume Rocker (`+ / –`).
- Microphone pinhole & Power button.
- iOS translucent blur glassmorphism pairing cards and OSD notifications.
